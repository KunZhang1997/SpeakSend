# SpeakSend

**Mac 上的语音输入与录音整理工作台。**

### 1. 全局语音输入：指哪说哪，自动剃掉口水词

在 AI 对话框、飞书、微信、邮件或任意编辑器里按住 `Fn` 开口即说，松手直接填入当前光标位置，自动去掉“呃、那个”等口头禅，保留你的真实语气与专有名词。

![全局语音输入与口水词清理](docs/images/v0.1.1/02-voice-input.png)

### 2. 长录音与混合笔记：边写边录，结论直查原话

既能先敲几行提纲再随时点麦克风接着口述，也支持戴耳机录制线上会议双方声音。左侧自动整理总览、已拍板与待办，点击任意结论即可定位右侧当时那句原话。

![长录音与混合笔记工作台](docs/images/v0.1.1/03-meeting-workbench.png)

### 3. 想法网络：告别录音坟场，旧记录自动成网

无需手动打标签或建双链，日常散步随记与会议复盘会在后台自动串联同类话题，支持按记录夹多选查看范围，随时翻出几个月前的每句原话。

![想法网络跨记录夹自动串联](docs/images/v0.1.1/04-idea-network.png)

### 4. 本机离线与开放存储：不按分钟扣费，直接存成 `.md`

可在设置中一键下载免费的 `Qwen3-ASR`、`Whisper` 本地语音模型并搭配本地 `Ollama` 整理引擎，断网可用、私密内容不出本机；每条记录实时存为本地 Markdown 文档，访达或 Obsidian 直接打开。

![本机离线模型与本地 Markdown](docs/images/v0.1.1/05-local-native.png)
