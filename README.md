# SpeakSend

**脑子想得比手快，按住说话秒出字。**

任何软件输入框按住 `Fn`，松手就出干净文字。开长会不用重听，点结论直查原话。几个月随口聊过的旧点子，还会自动连成网。

- **指哪说哪** — 光标停在哪就说在哪。按住 `Fn` 动嘴，松手秒出字，连粘贴都不用按。
- **边写边录** — 先敲三行提纲，点麦克风接着往下聊。AI 拎出重点，句句对得上原话。
- **旧话成网** — 不用建双链，也不用打标签。前几个月随口聊过的灵感，自动串成一张网。

### 只剃掉口水词，绝不乱改你的原意。

跟 AI 交代五百字背景，敲键盘手都酸了，动嘴只要十几秒。回飞书、微信不用发长语音，松手直接变成清爽文字。自动删掉“呃、那个”，不改油腻 AI 腔；改过一次的人名和缩写，下次开口直接写对。
